# Students Performance in Exams - Data Analysis

This project analyzes how various demographic factors (like parental education, lunch types, and test preparation) impact high school students' exam scores using Python and Pandas.

## Key Insights Discovered
* **Test Prep Impact**: Students who completed the preparation course scored higher across all subjects.
* **Socioeconomic Factors**: Lunch type and parental education levels showed noticeable correlations with average scores.
* **Subject Correlation**: There is a strong positive correlation between reading and writing scores.

## Technologies Used
* Python 3
* Pandas
* Chardet (for encoding detection)

## How to Run
1. Clone this repository.
2. Ensure you have the required libraries installed: `pip install pandas chardet`
3. Run `python analysis.py`
