# 📊 Student Performance Analysis

A Python data-analysis project exploring relationships between student performance and factors such as test preparation, lunch category, and parental education.

## 🔎 Questions Explored
- How does test preparation relate to average scores?
- How do lunch categories compare across subjects?
- How does parental education relate to performance?
- How strongly are reading and writing scores correlated?

## 🧰 Tech Stack
- Python 3
- Pandas
- Chardet
- Data analysis and visualization

## 📈 Findings
The dataset shows differences in average performance across test-preparation, lunch, and parental-education groups. Reading and writing scores also show a strong positive relationship.

These are associations in the dataset, not proof that a factor causes academic performance.
